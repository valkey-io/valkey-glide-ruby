# CLAUDE.md

Valkey GLIDE Ruby (`valkey-glide-rb`) is the official Ruby binding for Valkey and Redis OSS. It uses the shared Rust **glide-core** driver via the **glide-ffi** C library. This repository is separate from the [valkey-glide](https://github.com/valkey-io/valkey-glide) mono-repo (Python, Java, Node, Go).

The shared agent context lives in [AGENTS.md](./AGENTS.md) and is imported below: repository overview, architecture, build and test commands and prerequisites, contribution requirements, guardrails, and project structure. AGENTS.md is the single source of truth for that operational content; do not duplicate it here. This file adds only the Claude-specific rules that layer on top.
